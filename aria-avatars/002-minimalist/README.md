# 002 — Minimalist Assistant

**Palette:** Near-black (#1a1a1a), white accents, cyan highlight (#00e5ff) on hover
**Shape language:** Octagonal head, single LED-strip eye bar, minimal mouth line
**Personality:** Professional, calm, tech-forward without being cold. The octagon references precision engineering. The single-bar eye is iconic and readable.

## Interactions
- Hover: eye bar and top accent switch to cyan, mouth lifts slightly

## Use case
Best for dashboard headers, system tray icons, or any context needing a clean, business-facing look. Scales extremely well — the eye bar stays readable at 16px.
