# 004 — Soft Orb

**Palette:** Deep indigo-black (#0a0a14), violet gradient (#c4b5fd → #7c3aed → #1e0050)
**Shape language:** Perfect sphere with radial gradient, specular highlight, rim light, floating animation
**Personality:** Thoughtful, calm, almost spiritual. Feels like a consciousness rather than a machine. The floating animation reinforces this — it doesn't sit still, it exists.

## Interactions
- Constant: CSS float animation (translateY, 3s cycle)
- Hover: eyes brighten to white, outer glow intensifies, smile becomes more visible

## Use case
Best for ambient/ambient status displays, loading states, or representing Aria in reflective/thinking contexts. The orb metaphor works well for "AI presence" without anthropomorphizing too hard.
