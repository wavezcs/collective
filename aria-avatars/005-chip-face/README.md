# 005 — Chip Face

**Palette:** Near-black (#0e0e0e), amber/gold (#f59e0b), dark amber grid
**Shape language:** Square IC chip body with pin arrays on all four sides, classic IC corner notch, amber LED eyes, 7-segment "A" mouth spelling out the Aria logo shape
**Personality:** Classic AI/computer chip iconography. The mouth displays a stylized "A" in 7-segment format — a nod to Aria's name baked into the design. Gold/amber palette reads as premium hardware.

## Use case
Best for hardware-adjacent contexts, settings panels, or any surface where "this is serious AI infrastructure" should be communicated. The IC pin rows are distinctive at 32px and above.
