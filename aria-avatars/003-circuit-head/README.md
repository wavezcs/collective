# 003 — Circuit Head

**Palette:** Deep green-black (#050d05), phosphor green (#39ff14)
**Shape language:** Rectangular head, external trace lines with via dots, segment-display mouth
**Personality:** Hacker aesthetic. Matrix/terminal energy. Communicates deep technical capability. Less friendly, more capable-feeling.

## Interactions
- Hover: all green elements brighten to lime (#7fff00), border brightens

## Use case
Best for developer tools, terminal UIs, or when Aria is operating in a technical/coding context. The phosphor green reads as "active system" immediately.
